# Nadeem's AI Chatbot 🤖

A full-stack AI-powered Chatbot application built using React (Vite) and Node.js/Express with OpenAI integration.

## 🚀 Features
- Interactive AI conversational interface
- Modern, responsive UI
- Express server integration with OpenAI API
- Secure environment configuration

## 🛠️ Tech Stack
- **Frontend:** React, Vite, CSS / Tailwind
- **Backend:** Node.js, Express.js
- **API:** OpenAI API
